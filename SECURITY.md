# Security

Report vulnerabilities privately to the maintainers of
[FABBricate IT Solutions](https://github.com/FABBricate-IT-Solutions)
or via GitHub Security Advisories on this repository.

Do not open a public issue for an unfixed vulnerability.

This repository runs:

- `cargo-audit` on every push, pull request, and weekly
- `cargo-deny` for advisories, licenses, and crate sources
- Dependabot version updates (Cargo and GitHub Actions)
- GitHub Dependabot security updates (enabled on the repo)
